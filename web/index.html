정확도 막대의 가는 선은 Wilson 95% 신뢰구간입니다. 오른쪽 열은 관측된 차이가 참값이라고 가정했을 때 바로 아래 순위 시스템과 양측 95%로 갈리는 질문 수(정확해, 검정력 약 50% 기준)입니다. 검정력 80% 기준은 이보다 약 두 배 큽니다(계산기 참고).

질문 수에 따른 순위 안정성

순위 역전 확률 계산기

정확도 차이가 gap인 두 시스템을 질문 n개로 비교할 때, 순위가 뒤집혀 보일 확률입니다. gap과 불일치율을 참값으로 가정합니다. 같은 질문으로 둘을 채점하므로, 한쪽만 맞힌 질문의 비율(불일치율)이 결과를 크게 바꿉니다. 비우면 두 시스템이 질문별로 독립이라고 보고 계산합니다.

읽을 때 주의할 점

  • 정답 여부(O/X)는 데이터셋 작성자가 LLM 평가기 4종의 투표로 정한 값입니다. 작성자는 금융 도메인에서 사람 평가와 약 8% 어긋났다고 밝혔습니다.
  • 시스템 23개는 한 회사가 만든 벤치마크에서 나왔고, 질문은 300개뿐이라 300보다 큰 n에 대한 값은 같은 질문 분포를 가정한 외삽입니다.
  • 질문 수와 순위 안정성을 부트스트랩으로 재는 방법은 정보검색의 topic set size 연구에서 쓰는 표준 방법입니다. 여기서 새로운 것은 방법이 아니라 한국어 RAG 리더보드에 적용한 결과와 계산기입니다.
